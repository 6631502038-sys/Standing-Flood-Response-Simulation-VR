# Standing-Flood-Response-Simulation-VR
A VR Learning Game Based on Japanese Disaster Response Standards

An immersive Virtual Reality (VR) educational game designed to train users on proper flood response procedures during standing flood scenarios in Southern Thailand, based on Japanese disaster response priority standards.

📌 About The Project

Standing floods are a recurring disaster in Southern Thailand, yet public awareness and systematic response training remain limited. This project addresses the gap by leveraging Virtual Reality (VR) and Game-Based Learning (GBL) to provide a safe, repeatable, and interactive training environment.

Key Features

Scenario-Based Learning: Based on real-world flood conditions in Southern Thailand and past flood events.

Japanese Standard Framework: Structured according to Japan Meteorological Agency (JMA) & Ministry of Land, Infrastructure, Transport and Tourism (MLIT) priority principles.

3-Stage Gameplay: Interactive tasks guiding players through Before, During, and After flood scenarios.

VR Interaction: Immersive hand-tracking/controller interactions using Unity's XR Interaction Toolkit.
